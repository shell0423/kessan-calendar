# 次回決算発表日 — 例年より早いか、遅いか

**閲覧はこちら → https://shell0423.github.io/kessan-calendar/**

全上場銘柄(ETF等を除く約4,000社)の**次回の決算発表日**と、それが**例年(前年・前々年・3年前の同じ四半期)
と比べて早いか遅いか**を、毎営業日更新で一覧・カレンダー表示しています。

- 確定日: 会社が公表した予定日(J-Quants「決算発表予定日」・JPX「決算発表予定日」)
- 予想日: 未公表の会社は前年同期の発表日の1年後(休場日は翌営業日)を薄字で表示
- ズレは「暦日の差」と「期末からの日数の差」の2通り。6日超は ⚠️
- 銘柄詳細: 株価チャート(決算発表日▲・適時開示●のマーカー)、ヒストリカルPER、PER/PBR/配当利回り、開示一覧

計算方法・留保はページ内の「使い方」タブにまとめています。

## 更新タイミング

平日21時すぎに自動更新(その日の終値ベース)。

## このリポジトリについて

生成物(HTML・銘柄別JSON)だけを置いています。毎日全ファイルが差し替わるため、
**履歴は保持せず毎回1コミットに作り直して force push** しています(過去版は残りません)。

## 注意

- 個人が J-Quants / JPX / TDnet の公開データから自家生成した**非公式の表**です
- 予定日は会社都合で変更されます。必ず会社の開示で確認してください
- 投資判断は自己責任でお願いします
